Single page or multiple pages?

The template uses Next.js App Router with page transitions. How deep should the site go?

A

Single-Page Site

Home page only — Hero, Services (bento), How It Works, Solutions Showcase, Financing, Testimonials, Zoho Form, Footer. Everything scrolls. Fastest to ship, easiest to maintain. Good for launch.

B

Multi-Page with Service Detail Pages

Home + individual page per service (Turnkey, Incorporation, Identity, Branding, Management). Each service page has its own hero, features list, pricing, and CTA. Better for SEO and conversion per service.

C

Home + Contact/Booking Page

Home page (all sections) + a dedicated "Book a Strategy Call" page that embeds the Zoho CRM lead form. Simple 2-page site. Fast to ship, clean CTA destination.
